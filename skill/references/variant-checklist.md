# Variant block checklist — fill EVERY field

Field-by-field quality bar for a client variant. The nearest base pattern:
- **hnw** — premium financial / luxury (Capital One pattern)
- **cpg** — consumer product, considered purchase (Bridgestone pattern)
- **b2b** — data/services sold to firms (Expana pattern)
- **em** — market entry / geographic expansion

## Identity
- [ ] `key` — lowercase client name (`expana`, `capitalone`, `bridgestone`)
- [ ] Fictional adjacent brand for mock ads (Aurum/Sentra/Treadline/Volta
      pattern) — same category, invented name, never the prospect's own logo

## The typed question (scene 1)
- [ ] ≤160 chars, first person plural, names their category + a real decision
- [ ] Contains one word the Brain can flash orange (the pivot concept)
- Bad: "How can we improve our marketing?"
- Good: "Two of our five card benefits drive most sign-ups — which two, and
  for which member segment?"

## The matrix (the heart of the video)
- [ ] Columns (3-4): what they would test — claims, formats, price frames,
      benefit territories. Their vocabulary, 1-2 words each.
- [ ] Rows (3): who/when — audiences, occasions, segments.
- [ ] Winner cell chosen deliberately: the intersection a smart researcher
      would bet on, so the reveal feels earned.
- [ ] Ad variants color-coded A-D (adA..adD palette keys).

## Audience & fielding
- [ ] Audience chips / panel description in their world's language
- [ ] Incidence estimate plausible for that audience (niche B2B ≠ 55%)
- [ ] n sizes: 300-500 consumer, 150-300 B2B

## Platform signal mappings (if the scene is used)
- [ ] 3 mappings "X behavior = Y signal on Z platform," category-true
      (e.g., "Fleet manager forum post = engagement on LinkedIn")

## Takeaway numbers
- [ ] 2-3 outcome stats, internally consistent, none from the approved-proof
      list misquoted, none invented as *client results*  — frame as the demo
      scenario's numbers

## Tone check before render
- [ ] Every line survivable if the prospect's CEO reads it on mute
- [ ] Zero hype adjectives; motion + numbers carry the confidence
- [ ] "Augmenting researchers, never replacing them" spirit intact
